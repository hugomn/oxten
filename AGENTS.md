## Application architecture

- The home page is a self-contained document in `src/home/v5.html`, generated by `scripts/build-home.py` from the design source and served as is by the index route. Edit the design source and regenerate; do not hand-edit the generated file.
- Invite requests go through `src/routes/api/waitlist.ts`, validated with the shared schema; no visitor can read stored addresses.
- Database schema lives in `drizzle/` and `supabase/`.
